# AUREON Theme Contract v0.3

CSS tokens: `--au-bg`, `--au-surface`, `--au-text`, `--au-surface-text`, `--au-accent`, `--au-accent-text`, `--au-muted`, `--au-border`, `--au-nav`, `--au-card`, `--au-hover`.

Never copy literal colors into module CSS. Use tokens. Contrast fallback for text is computed at runtime. Theme selection localStorage is temporary and device-local. Auto mode follows Home Assistant darkMode; dark/light modes currently force Forest/Sage when necessary. Palette references from ControlRoom audit; no functional source code copied.
